# Capabilities

Run `capybari capabilities` for the live list from your installed version.

| ID | Name | Targets | Network | Repository |
|---|---|---|---|---|
| `inventory` | Repository Inventory | repository | none | capybari-core (built-in) |
| `web-snapshot` | Website Snapshot | website | required (target only) | capybari-core (built-in) |

Each capability's repository contains `docs/methodology.md`: what it detects, how, severities, and known false positives.
